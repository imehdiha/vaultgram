# نصب Vaultgram

Vaultgram یک روبات خصوصی تلگرام است. سندها را به‌صورت رمزگذاری‌شده در Cloudflare KV و اطلاعات محرمانهٔ کوتاه را در D1 نگه می‌دارد. برای نصب تازه به حساب Cloudflare، Node.js نسخهٔ ۲۰ یا بالاتر، و یک روبات **جدید** ساخته‌شده با [BotFather](https://t.me/BotFather) نیاز دارید.

مسیر اصلی روبات با سرویس واقعی آزمایش شده است. نصب‌کننده آزمون خودکار و dry-run را گذرانده و منتظر نخستین آزمایش مستقل است.

برای دریافت مخزن و شروع نصب، این سه دستور را **به‌ترتیب و هر کدام در یک خط** اجرا کنید. خط اول پروژه را دریافت می‌کند، خط دوم وارد پوشهٔ آن می‌شود و خط سوم نصب‌کننده را اجرا می‌کند:

```bash
git clone https://github.com/imehdiha/vaultgram.git
cd vaultgram
npm run setup
```

نصب‌کننده وابستگی‌ها را نصب می‌کند، در صورت نیاز ورود Cloudflare را باز می‌کند، توکن روبات را بدون نمایش هنگام تایپ می‌گیرد، منابع مجزای Cloudflare را می‌سازد، پنج Secret را تنظیم می‌کند، مهاجرت‌های D1 را اجرا می‌کند و webhook و منوی تلگرام را ثبت می‌کند. اگر روبات از قبل webhook داشته باشد، نصب تازه متوقف می‌شود. اگر کار نیمه‌تمام بماند، همان دستور را دوباره اجرا کنید؛ Secretهای اولیه از فایل بازیابی قبلی استفاده می‌شوند.

نصب‌کننده یک فایل بازیابی **بیرون از مخزن** با دسترسی محلی محدود می‌سازد. وقتی خواست، آن را در مدیر رمز عبور خود ذخیره کنید و `SAVED` بنویسید. کلید `VAULT_ENCRYPTION_KEY` را حتماً نگه دارید؛ بدون آن، سندها و اطلاعات رمزگذاری‌شده بازیابی نمی‌شوند. پس از اطمینان از نسخهٔ پشتیبان، می‌توانید نسخهٔ محلی فایل را پاک کنید. این فایل را در GitHub، پیام‌رسان یا issue قرار ندهید.

در پایان، روبات را در گفت‌وگوی خصوصی باز کنید و `/claim` را همراه با مقدار `BOOTSTRAP_SECRET` همان فایل بفرستید. نخستین استفادهٔ درست، حساب مالک را می‌سازد. سپس می‌توانید گاوصندوق، دسته و سند بسازید و عضو دیگری را با دعوت یک‌بارمصرف اضافه کنید.

برای دیدن مراحل بدون انجام نصب: `npm run setup -- --dry-run`. این نصب‌کننده مخصوص نصب تازه است؛ برای راه‌اندازی دستی یا نگهداری نصب فعلی، [راهنمای دستی](MANUAL_INSTALL.md) را ببینید.

اگر نصب در میانه متوقف شد، خطای آخر را بخوانید و پس از رفع مشکل همان `npm run setup` را دوباره اجرا کنید؛ کلید رمزگذاری قبلی حفظ می‌شود. اگر پیام «روبات از قبل webhook دارد» دیدید، یک روبات تازه در BotFather بسازید. برای گزارش مشکل در GitHub، توکن، فایل بازیابی، شناسهٔ شخصی یا محتوای سند را نفرستید.
