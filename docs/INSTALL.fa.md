# راهنمای نصب والتگرام

این راهنما برای کسی است که می‌خواهد **یک روبات تازه** برای خودش راه‌اندازی کند. هر دستور را جداگانه در ترمینال اجرا کنید و صبر کنید تا تمام شود، سپس سراغ دستور بعدی بروید. نوشته‌های داخل کادرهای دستور باید دقیقاً همان‌طور که هستند تایپ شوند.

نصب‌کنندهٔ تازه هنوز توسط فردی خارج از تیم پروژه آزمایش نشده است. مسیر اصلی روبات با سرویس‌های واقعی آزمایش شده و بررسی‌های خودکار نصب‌کننده موفق بوده‌اند. اگر در نصب گیر کردید، متن خطا را بدون هیچ رمز یا توکنی در [بخش مشکلات مخزن](https://github.com/imehdiha/vaultgram/issues) بفرستید.

## ۱. چیزهایی که باید آماده کنید

- یک حساب کلادفلر.
- یک حساب تلگرام و **روبات جدیدی** که با [بات‌فادر](https://t.me/BotFather) ساخته‌اید. توکنی را که بات‌فادر به شما می‌دهد نزد خود نگه دارید. از روبات فعلی یا روباتی که جای دیگری فعال است استفاده نکنید.
- رایانه‌ای که «گیت» و «نود جی‌اس» نسخهٔ ۲۰ یا بالاتر روی آن نصب است. «ان‌پی‌ام» همراه نود جی‌اس نصب می‌شود. اگر این ابزارها را ندارید، آن‌ها را از [سایت رسمی گیت](https://git-scm.com/downloads/) و [سایت رسمی نود جی‌اس](https://nodejs.org/en/download) نصب کنید.

برای ساخت روبات، به بات‌فادر در تلگرام پیام زیر را بفرستید:

<div dir="ltr">

```text
/newbot
```

</div>

سپس نام نمایشی و نام کاربری روبات را مطابق پرسش‌های بات‌فادر وارد کنید. نام کاربری باید به «bot» ختم شود. در پایان، بات‌فادر توکن روبات را می‌دهد؛ آن را فقط هنگام اجرای نصب‌کننده وارد کنید.

برای بررسی آماده‌بودن ابزارها، این سه دستور را جداگانه در ترمینال اجرا کنید. هر سه باید شمارهٔ نسخه نشان دهند؛ نسخهٔ نود باید دست‌کم ۲۰ باشد.

<div dir="ltr">

```bash
git --version
```

</div>

<div dir="ltr">

```bash
node --version
```

</div>

<div dir="ltr">

```bash
npm --version
```

</div>

## ۲. دریافت پروژه

ترمینال را باز کنید. دستور زیر پوشهٔ پروژه را در محل فعلی می‌سازد و فایل‌ها را داخل آن دریافت می‌کند:

<div dir="ltr">

```bash
git clone https://github.com/imehdiha/vaultgram.git
```

</div>

حالا با دستور زیر وارد همان پوشه شوید. این دستور چیزی را نصب نمی‌کند؛ فقط محل کار ترمینال را عوض می‌کند:

<div dir="ltr">

```bash
cd vaultgram
```

</div>

## ۳. اجرای نصب‌کننده

وقتی ترمینال داخل پوشهٔ پروژه است، این دستور را اجرا کنید:

<div dir="ltr">

```bash
npm run setup
```

</div>

نصب‌کننده کارهای فنی را خودش انجام می‌دهد. در طول کار فقط این موارد را از شما می‌خواهد:

1. **ورود به کلادفلر:** اگر قبلاً وارد نشده‌اید، نشانی‌ای در ترمینال نمایش داده می‌شود. آن را در مرورگر باز کنید و ورود را تأیید کنید. اگر چند حساب کلادفلر دارید، شمارهٔ حساب درست را در ترمینال وارد کنید.
2. **توکن روبات:** توکن روبات جدید را از بات‌فادر کپی و در ترمینال جای‌گذاری کنید، سپس کلید ورود را بزنید. هنگام تایپ یا جای‌گذاری، چیزی روی صفحه دیده نمی‌شود؛ این طبیعی است. توکن را در گفت‌وگو، عکس صفحه یا فایل پروژه قرار ندهید.
3. **پشتیبان‌گیری:** نصب‌کننده محل یک «فایل بازیابی» را نشان می‌دهد. این فایل بیرون از پوشهٔ پروژه است. همهٔ محتوای آن را در مدیر رمز عبور خود ذخیره کنید و مطمئن شوید بعداً به آن دسترسی دارید. سپس برای تأیید، عبارت زیر را در ترمینال بنویسید و کلید ورود را بزنید:

   ```text
   ذخیره شد
   ```

   اگر فایل بازیابی گم شود، داده‌های رمزگذاری‌شده را نمی‌توان بازیابی کرد. این فایل را در گیت‌هاب یا پیام‌رسان نفرستید.

پس از آن منتظر بمانید تا نصب تمام شود. نصب‌کننده منابع کلادفلر را می‌سازد، روبات را وصل می‌کند و در پایان نشانی روبات و پیام آماده‌بودن را نشان می‌دهد. خروجی ابزارهای کلادفلر ممکن است انگلیسی باشد؛ لازم نیست دستور دیگری از روی آن حدس بزنید.

## ۴. ساخت حساب مالک

روبات تازهٔ خودتان را در **گفت‌وگوی خصوصی تلگرام** باز کنید. در فایل بازیابی، مقدار روبه‌روی نام زیر را پیدا کنید:

<div dir="ltr">

```text
BOOTSTRAP_SECRET
```

</div>

به روبات یک پیام بفرستید که ابتدا فرمان زیر باشد، بعد **یک فاصله** و سپس مقدار همان رمز. در نمونهٔ زیر، `abc123` را با مقدار واقعی داخل فایل خودتان جایگزین کنید:

<div dir="ltr">

```text
/claim abc123
```

</div>

اولین درخواست درست، شما را مالک می‌کند. روبات تلاش می‌کند پیام دارای رمز را از چت پاک کند. اگر پیام باقی ماند، خودتان آن را پاک کنید. سپس از منوی روبات یک گاوصندوق، یک دسته و یک سند آزمایشی بسازید.

## اگر نصب متوقف شد

- همان دستور مرحلهٔ ۳ را دوباره اجرا کنید. نصب‌کننده ادامهٔ نصب قبلی را با همان رمزها انجام می‌دهد. فایل بازیابی را پیش از پایان نصب پاک نکنید.
- اگر گفت روبات از قبل به یک نشانی دیگر وصل است، با بات‌فادر یک روبات **تازه** بسازید و نصب را برای آن شروع کنید. نصب‌کننده روباتِ در حال استفاده را تصاحب نمی‌کند.
- برای گزارش خطا، فقط متن خطا و مرحله‌ای را که در آن متوقف شده‌اید بفرستید. **توکن روبات، فایل بازیابی، رمز مالک، شناسهٔ شخصی و محتوای سند را نفرستید.**

این راهنما برای نصب تازه است. اگر قبلاً والتگرام را نصب کرده‌اید و می‌خواهید آن را به‌روزرسانی کنید، از [راهنمای نگهداری نصب موجود](MANUAL_INSTALL.md) استفاده کنید.
